# CloudPad Studio (Dev) v15.7.0

## Timeline-first Macro Studio
- Macro Studio now uses a solid background and a bounded editing workspace. Slots, macro name, saved/unsaved state and common controls stay at the top.
- The timeline is immediately visible. Selected action settings appear to its right on desktop and below it on narrow screens.
- The main action inspector shows Start and Duration, plus signed stick strength or trigger depth when relevant. Gap/overlap and control reassignment are in Advanced.
- Recording source, imports/exports, clear, diagnostics, playback speed, precision modes and whole-sequence tools are under More. Existing features remain available.
- D-pad controls use descriptive up/down/left/right names. Short presses use compact blocks, and resize handles appear when the action is selected.

## Editable waits
- Click a striped wait to edit its duration directly with numeric or +/- controls.
- Resize a selected wait using its right handle, or delete it to close the gap.
- Leading, internal and trailing waits update subsequent timing and total duration while preserving the actions' hold lengths and analog values.

## Add controls directly
- One Add button opens a picker for each controller button and stick axis, including descriptive D-pad controls and Wait.
- New actions start after the selected action by default. Start together places the new action at the same time.
- Conflicting overlaps on the same control are rejected rather than silently changing another action.

## Undo, redo and playback
- Undo/Redo covers timing edits, percentages, drag/resize, wait changes, additions, deletions, reassignment and name edits. Holding a percentage adjustment or dragging a slider is grouped into one edit.
- Ctrl/Cmd+Z and redo shortcuts work in the studio outside text inputs. Invalid entries can be cleared with Undo. History is bounded to 30 entries and a memory budget; it remains available after saving the current slot.
- Play previews the current valid draft without writing over the saved macro. Unsaved status remains visible until Save.
- Loop is now a toggle for the next playback. Stop still releases macro input; background-playback behavior is retained.
- Save is always accessible in the toolbar. Slot switching continues to offer Save / Discard / Cancel for unsaved edits.

## Validation
Local syntax, model and browser checks cover the workspace layout, mobile bounds, signed controls, grouped undo/redo, leading/internal/trailing wait edits and deletion, wait dragging, direct action selection, simultaneous actions, unsaved preview without persistent changes, loop toggle, save/error focus, menu access, bilingual UI, slot-switch protection, recording, background playback, repeated timing edits, touch/racing behavior, right-click isolation and Dev updates.

Development build for device/game testing. Stable Release unchanged.
