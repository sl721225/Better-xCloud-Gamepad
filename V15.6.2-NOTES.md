# CloudPad Studio (Dev) v15.6.2

## Compact horizontal editing
- Macro Studio expands to 900 px when space permits; it remains clamped on smaller screens.
- Action type, control and delete share the title row. Start, gap/overlap and hold duration are aligned horizontally. Wait presets and output/depth controls use two columns.
- Narrow screens wrap into smaller groups without horizontal overflow in the detail editor. The timeline fits the available width and updates its scale after resizing.

## Consistent start and gap editing
- Wait before action is now Gap / overlap: positive values represent waiting and negative values represent overlapping inputs.
- The preceding actions remain the reference while editing the selected action. Changing its start time does not silently replace that reference after chronological reordering. Start and gap update together.
- Actions with tied start times no longer incorrectly move an earlier action while editing a later one.
- Moving the second segment of an analog sequence now inserts a release at the old boundary when needed, keeping the earlier segment from stretching with it.
- Edits which overlap actions on the same control are rejected. Failed changes restore original event objects, times, implicit endpoints and total duration atomically.
- Error tracking uses stable event identities instead of array indices, so inserting endpoint events cannot attach an error to another action.
- Correcting an input preserves message space until Save, preventing the Save button from jumping under the pointer and losing the click.

## Validation
Pure logic tests cover 30 alternating start/gap changes, fixed references after reordering, tied starts, analog boundaries, unchanged hold durations and rollback. Browser tests cover the same field interactions, desktop horizontal layout and compact height, narrow bounds, percentage controls, timeline moving/resizing, neutral waits, error retention/focus and one-click saving. Background playback, physical recording and touch/racing layout regressions pass.

Development build. Stable Release unchanged.
