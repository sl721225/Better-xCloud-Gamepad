# CloudPad Studio (Dev) v15.6.3

## Slot selection opens the timeline immediately
- Opening Macro Studio loads the selected slot's timeline automatically, including empty slots. The Edit this macro step has been removed.
- Selecting another of the six slots updates the selected slot, name and timeline together.
- If there are no content changes, switching is immediate and asks nothing. Changing the timeline's viewing mode alone is not an unsaved content change.
- With unsaved name, event, timing, percentage or invalid-field edits, switching offers Save and switch / Discard and switch / Cancel, keep editing. Selection stays on the old slot until a choice succeeds.
- Save commits the old slot before loading the target, without a second confirmation. Invalid drafts or storage failures stay on the old slot and retain the edits.
- Cancel preserves the current draft. Discard restores saved data. Saving or discarding within the editor keeps its timeline open.
- Closing and reopening the window preserves the current draft. Quickbar, keyboard and controller launches share the navigation protection when changing slots.

## Recording and data updates
- Starting a new recording with an unsaved draft first offers the same save/discard/cancel choice, so an edited name or timeline cannot be silently overwritten by recording.
- Timeline editing is read-only during recording. Once recording finishes, a clean editor reloads the new recorded data automatically.
- Clearing a slot reloads its empty editor immediately. Importing over an unsaved current draft requires saving or discarding it first.
- The Add simultaneous action / Add event button names are unchanged in this patch.

## Validation
Browser tests cover initial auto-open, all six slots without prompts, empty-slot editing, viewing-mode-only changes, dirty names and times, save/discard/cancel, invalid inputs, storage failure rollback, window-close preservation, external-launch protection, recording with unsaved edits, source refresh after recording and bilingual prompts. Existing timeline, neutral-wait, repeated time-edit, percentage, background-playback, physical-recording, touch/racing and right-click isolation checks pass.
