# CloudPad Studio (Dev) v15.5.0

## Macro Studio
- Macros now open in a separate draggable floating window without moving the gamepad panel. Closing the window keeps unsaved edits and does not stop recording or playback.
- Window positions are saved and kept within the viewport. Reset positions from the window header or Settings → Shortcuts / protection.
- Compact recording-source selector and Record / Play / Loop / Stop controls retain large SVG icons.
- One macro-name field; while editing that slot, changes apply to the draft until Save. No duplicate draft-name or shorthand-code field.

## Timeline editing
- Simple mode pairs digital presses and releases into actions with start, wait and hold duration. Virtual recordings default to Simple; new physical recordings default to Precise. Modes can be changed manually.
- Simple time controls show one decimal with 0.1-second steps and short-press / 0.1 / 0.5 / 1-second presets. Short press is 80 ms. Untouched recorded times and analog values retain their original precision.
- “Move following actions together” is enabled for new editing sessions. Changing A from 0.5 to 1 second moves later actions by 0.5 second. Turn it off to preserve overlapping inputs.
- Precise mode retains individual timestamped events and millisecond steps, time sorting and whole-sequence shifting.
- Digital states use Hold / Release buttons. Sticks use direction, strength sliders and Center / ⅓ / ½ / ⅔ / Full presets. LT / RT use depth sliders and equivalent presets.
- Total duration automatically follows the final event plus explicit tail wait.
- Invalid numeric edits stay visible, with red outlines and local ranges. Save jumps to the first erroneous page, scrolls to the field and focuses it. Drafts are not saved until errors are corrected.

## Quickbar and cleanup
- Drag the handle with mouse or touch; the bar snaps to either side, including when collapsed. Position is saved and clamped after viewport changes.
- Single / Loop mode affects the next launch only. Click the currently playing slot to stop; another slot switches playback. Running loops show ↻.
- Empty slots are hidden from the quickbar; all six remain in Macro Studio. Add / manage macros remains available.
- Removed AFK controls and runtime behavior. Existing backups containing old AFK settings still import; macros can provide repeated actions.
- Existing background playback, touch/racing layouts, right-click automation, bilingual UI and Dev updates remain available.

## Validation
Local JavaScript syntax and browser checks cover paired-action timing, optional overlapping inputs, precision preservation, cross-page validation/focus, draft naming and closing behavior, analog presets, drag/resize, quickbar loop switching, legacy backups, physical/virtual recording, right-click output isolation, touch/racing layout behavior, background playback and Dev update checks.

Real Xbox stream behavior still needs device/game testing. This is a development build; the stable Release remains v15.3.0.
