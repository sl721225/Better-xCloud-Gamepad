# Better xCloud Gamepad

用於 Xbox Cloud Gaming 的虛擬手把 Userscript，支援觸控操作、賽車模式、實體手把監看、按鍵自動化、六組巨集及自訂佈局。

## 安裝

1. 在瀏覽器安裝 Tampermonkey 或 Violentmonkey。
2. 開啟 `Better-xCloud-Gamepad.user.js`。
3. 將完整內容貼入新腳本並儲存。
4. 重新整理 Xbox Cloud Gaming 頁面。

## 目前版本

`v14.1.0`

## 巨集備份

巨集頁面可匯出目前槽位或全部六組 JSON。匯入前會顯示預覽，並在覆蓋既有巨集前再次確認。

## 注意

腳本設定儲存在瀏覽器網站資料中。更換瀏覽器、裝置或清除網站資料前，請先匯出巨集備份。
