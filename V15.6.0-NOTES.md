# CloudPad Studio (Dev) v15.6.0

## Editable action timeline
- Horizontal tracks separate buttons, LT/RT and each stick axis. Held inputs appear as bars; overlapping controls play simultaneously.
- Click a bar to select its detail controls. Drag the bar to move it, or its right handle to resize its duration. Keyboard Enter / Space also selects a bar.
- Fit and zoom controls, horizontal scrolling, and an Add simultaneous action button simplify overlapping inputs. Large recordings (over 1,000 displayed actions) use the current page to keep rendering responsive.
- LT/RT and stick input now have editable hold durations as well as start times. Analog transitions remain separate segments; modifying a segment does not delete the next depth change.
- Inputs without a final release are shown through their existing macro end. Saving makes that endpoint explicit, so editing another control does not accidentally prolong the held input. Untouched recorded timestamps and values retain their precision.
- Example: RT starts at 0.3 seconds, holds 90% for 4.7 seconds, and releases at the 5-second loop boundary. LS movement or button actions can overlap independently.
- The Move following actions together option applies to duration/time edits and timeline dragging. Turn it off to edit one action while preserving other controls' timing. Conflicting extensions into a later action on the same control are rejected without changing the draft.

## Precise percentages
- Stick axes use a single signed slider from −100% to +100%, with 0 at the center. Direction dropdowns are removed. X: negative left / positive right. Y: negative up / positive down.
- LT/RT use 0–100% sliders.
- Both have − / + buttons for one-percentage-point adjustment. Holding a button repeats after a short delay, and releasing/canceling stops it.
- Optional numeric entry and positive/negative fraction presets remain available. Invalid percentages are highlighted and block saving, including errors on other pages.

## Validation
Local syntax, pure logic and browser tests cover the 0.3–5-second RT example and repeated loop boundaries, simultaneous RT/LS/A output, implicit endpoints, analog transitions, signed sliders, short and long presses on percentage buttons, timeline selection/move/resize, exact recorded-value preservation, cross-page validation/focus, draft naming/save/close behavior, touch/racing layouts, background playback, physical recording, right-click isolation and Dev updates.

This is a development build for device/game testing. The stable Release remains unchanged.
